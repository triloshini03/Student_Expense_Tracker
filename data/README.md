# Student Expense Tracker

A simple Java-based application designed to help students manage and track their daily expenses.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Delete an expense using ID
- Input validation
- Save expenses to a text file
- Load saved expenses when the application starts

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections
- File Handling

## Project Structure

- model - Contains the Expense class
- service - Handles expense operations
- storage - Saves and loads expense data
- utils - Validates user input
- data - Stores saved expenses

## How to Run

1. Open the project in VS Code.
2. Open Main.java.
3. Run the application.
4. Select options from the menu.
