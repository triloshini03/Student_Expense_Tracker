# Student Expense Tracker

## About the Project
Student Expense Tracker is a Java-based application designed to help students manage and track their daily expenses.

## Features
- Add daily expenses
- View expense records
- Organize expense data
- Track spending details

## Technologies Used
- Java
- File Handling
- VS Code

## Project Structure
- `src/com/expense` – Java source files
- `data` – Stores expense data

## How to Run
1. Clone or download the repository.
2. Open the project in VS Code.
3. Compile and run the main Java file.
